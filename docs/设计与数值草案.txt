一、已经定下来的规则
----------------------------------------------------------------
1. 材料（各种锭/合金）：全部在「冶炼炉」里烧制
2. 装备：在工作台合成
3. 升级路线装备：在锻造台升级（无需锻造模板）
4. 冶炼炉不做"燃烧按钮"：放入燃料和材料后自动开始烧，
   和原版熔炉一致（去掉按钮能少一大堆状态同步的坑）
5. 冶炼炉有 5 个输入槽，配方「无序匹配」，类似农夫乐事的锅：
   把需要的材料放进去就行，不需要摆位置
6. 每个配方默认「每种材料各消耗 1 个」，产出 1 个
7. 燃料不足时停止燃烧，玩家补燃料后继续（原版逻辑）

二、冶炼炉参数
----------------------------------------------------------------
- 单次烧制时间：200 游戏刻（10 秒），可写在配方里单独设置
- 经验：写在配方里（0.1 ~ 2.0），玩家取走产物时给
- 燃料：完全沿用原版燃烧时间（煤炭 1600 刻 = 8 个物品）
- 输出槽满 / 材料不匹配 → 暂停，不消耗燃料

三、冶炼炉配方格式（JSON 示例）
----------------------------------------------------------------
文件：data/kalioupo_equipment/recipe/carbon_steel.json

{
  "type": "kalioupo_equipment:smelting",
  "ingredients": [
    "minecraft:iron_ingot",
    "minecraft:coal"
  ],
  "result": { "id": "kalioupo_equipment:carbon_steel_ingot", "count": 1 },
  "cooking_time": 200,
  "experience": 0.35
}

说明：
- ingredients 无序，顺序随便写
- 以后需要「2 个铁锭」时，写成 {"item": "...", "count": 2} 即可（先预留）
- 同一个输入能匹配多个配方时，按 datapack 加载顺序取第一个

六、关于"提升一排血量"
----------------------------------------------------------------
你说的一排 = 玩家 20 点血（10 颗心）。
如果 +20，等于血量翻倍，配合 35 点护甲会非常夸张。
建议三选一（也可以只在穿满全套时生效）：
  A. 全套 +6 最大生命（3 颗心）—— 保守
  B. 全套 +10 最大生命（5 颗心）—— 推荐
  C. 全套 +20 最大生命（一排）—— 爽感优先，但需要削护甲
